# Unpacker

iPhone app that removes the password-protected zip layers from files downloaded from Baidu Netdisk, for a whole batch at once.

The Baidu files are zip archives with a misleading extension (e.g. `.pdf`), holding another zip with the same password. Unpacker detects archives from their contents (no renaming), removes every layer, and puts the final files in one folder per original.

## Use

1. In Baidu Netdisk, Share / "Open in…" each file → **Unpacker**. Files wait under *To unpack*. Or tap **+** to pick files from the Files app.
2. Settings (gear) → enter the password (one per line if there are several).
3. Optional, Settings → **Export destination**: pick a folder once (e.g. the Unzip app's folder in Files). Every finished batch is copied there automatically.
4. **Unpack all**. The whole run goes into one folder, `Batch 2026-11-03 14-30/`, with one sub-folder per original file.
5. Results are in the Files app under On My iPhone › Unpacker › `Batch …`. From there a whole batch folder can be imported into Unzip, moved, copied or AirDropped. In the app, swipe right on a batch to export it again or "Share folder" (an extra; folder sharing between apps is unreliable on iOS, so nothing depends on it).

Successful originals move to `Originals/` (or are deleted if you turn that on). Middle layers are always deleted. Failed files stay in *To unpack* with the reason shown.

### Shortcuts

- **Unpack Inbox**: unpacks everything waiting and returns the unpacked files (chain with "Save to Photo Album", "Save File", etc.).
- **Add Files to Unpacker**: takes files (e.g. from the share sheet) and optionally unpacks them straight away.

## Supported

- Zip with WinZip AES (128/192/256, AE-1/AE-2) and legacy ZipCrypto
- Stored and Deflate compression, Zip64
- GBK/GB18030 (Chinese Windows) filenames and the Info-ZIP Unicode Path field
- Any number of nested layers (up to 6); zip-based documents (.docx, .epub, …) are left alone
- 7z and RAR are detected and reported, not extracted

## Build

No Mac needed: GitHub Actions (`.github/workflows/build.yml`) runs the unit tests on macOS, then builds an unsigned `Unpacker-unsigned.ipa` and uploads it as a workflow artifact. Sign and install it with Sideloadly (free Apple ID: re-sign every 7 days) or a paid developer account.

Local build on a Mac: `brew install xcodegen && xcodegen generate && open Unpacker.xcodeproj`.

Core logic lives in `Core/` (Swift package `UnpackCore`, no dependencies: CommonCrypto + Compression). `swift test --package-path Core` runs the tests. Test fixtures are generated by `scripts/make_fixtures.py` (needs `pip install pyzipper`) and contain only generated data.
